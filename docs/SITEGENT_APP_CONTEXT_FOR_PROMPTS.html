One-line explanation: SiteGent is a WhatsApp-first AI operations app for South African contractors. It turns messy customer job messages into editable job cards, quotes, invoices, follow-up messages, and saved company job records using the contractor's own price list.

1. Product Goal

The goal is to help busy contractors and admin staff quote faster from WhatsApp job requests. The app should reduce thinking, typing, and admin work. It should not become a heavy CRM.

  • Primary user: contractor, trades business owner, office admin, or estimator.
  • Market: South African contractors and service businesses using WhatsApp daily.
  • Main promise: paste a customer message, review a quote, save the job, export quote or invoice.
  • Important rule: SiteGent drafts prices, but a human must review before sending to a customer.

6. Main API Routes

  • /api/ai/extract: extracts a job and quote from a customer message.
  • /api/auth/signup: creates Supabase account and optionally company profile.
  • /api/auth/signin: signs in and returns session.
  • /api/auth/me: returns current user profile.
  • /api/auth/onboard: creates company profile for an existing user.
  • /api/pricing: gets, creates, updates, and deletes price-list items.
  • /api/operations/save: saves the operations pack: customer, job, message, quote, quote items, invoice, and AI task.
  • /api/saved-jobs: lists saved company jobs.
  • /api/invoices: lists invoices and updates invoice status.
  • /api/documents/[type]: renders saved quote or invoice export HTML.
  • /api/payments: records manual payment and marks invoice paid.
  • /api/feedback: records pilot feedback.
  • /api/analytics: tracks and reads app usage events.
  • /api/health, /api/readiness, /api/config/status: service status checks.

7. Database Tables

  • users: app profile linked to Supabase auth user and company.
  • customers: customer details extracted from WhatsApp messages.
  • workers: future worker records.
  • jobs: saved job cards with status, urgency, location, and scheduled date.
  • quotes: saved quote records scoped to company.
  • quote_items: line items for each quote.

  • invoices: draft/sent/paid/overdue/cancelled invoices.
  • messages: original WhatsApp-style customer messages and AI summaries.
  • payments: manual payment records.

11. What Is Still Missing

  • Real transactional save: save currently creates multiple rows in sequence. It should become one database function or transaction to avoid partial saves if one insert fails.
  • Better onboarding: users need a very simple first-run setup: company profile, add first prices, paste first message.
  • Better price-list importing: contractors may prefer paste/import price list from WhatsApp, Excel, or notes instead of adding one-by-one.
  • Quote trust indicators: every line should clearly say matched price, guessed price, or needs human check.
  • Scheduling: text like "tomorrow morning" is not a real date yet. Scheduling is basic.
  • Durable rate limiting: current rate limit is in-memory, which is fine for a tiny pilot but not enough for scale.
  • Observability: needs error tracking, logs, and simple admin visibility into failures.
  • Support process: for testers, there should be a WhatsApp number or form for quick bug reports.
  • Payments: payment tracking is manual. No Stripe/PayFast/Yoco integration yet.

12. What Could Go Wrong

Risk What Could Happen Fix
AI wrong price Customer gets a bad quote if user trusts draft blindly. Keep human review warning. Show matched vs guessed lines. Encourage price list setup.
Bad onboarding Tester signs up but does not understand company profile or pricing. Make setup wizard: Step 1 profile, Step 2 add prices, Step 3 paste message.
Partial save Customer/job created but quote/invoice fails. Move save into a database transaction or RPC function.
OpenAI cost Users spam extraction and burn credits. Limit requests per user/company and cache common extraction failures.
Privacy issue Contractor pastes sensitive customer data. Add clear privacy copy, avoid logging secrets, use RLS, and limit admin access.
Weak feedback loop You do not know why testers stop using it. Add one-click feedback and personally WhatsApp each tester after first use.
Too many features App becomes confusing and looks like a CRM. Only build features that make quoting faster or safer for first testers.

13. Best Next Features

  2. Paste price list: Let user paste lines like "Labour R950/day, callout R450, sealant R150" and create price items automatically.
  3. Quote confidence labels: Matched price, estimated price, missing detail.
  4. Better export design: More professional quote/invoice documents with company info, terms, and payment details.
  5. Tester feedback tracker: See which testers signed up, added prices, generated quote, saved job, exported invoice.
  6. Transaction-safe save: Save all operation rows in one database transaction.
