SiteGent

WhatsApp Job Messages Into Quotes, Invoices, And Saved Jobs

SiteGent helps South African contractors turn messy customer WhatsApp messages into editable job cards, quote drafts, invoice drafts, and follow-up messages.

Paste the WhatsApp. Check the quote. Save the job.

Contractors already run their work from WhatsApp. SiteGent gives them a simple workspace that reads the customer message, uses their own price list, prepares the quote and invoice, and keeps the job saved privately for their company.

Live app: https://sitegent.vercel.app

What SiteGent Is

SiteGent is a simple AI operations assistant for contractors, trades businesses, and small service teams. It is built for people who receive job requests through WhatsApp and need to quote quickly without losing track of the job.

It is not trying to be a heavy CRM. The goal is speed, clarity, and fewer admin mistakes.

The Problem

Many contractors receive work requests like this:

“Hi, I need 6 cubes river sand and 2 cubes 19mm stone delivered before Friday. Please quote me. My number is 082 555 0142.”

From that message, someone still has to understand the job, ask missing questions, estimate quantities, check prices, create a quote, save the customer details, and later create an invoice. That admin slows people down.

The Solution

SiteGent takes the messy message and prepares the working draft:

  • Customer details
  • Job card
  • Quote draft in Rand
  • Invoice draft
  • Customer follow-up message
  • Saved company job record

The contractor still reviews and approves the quote before sending anything to a real customer.

What The App Has Today

Feature What It Does
Sign up and sign in Users can create an account and return to their private workspace.
Company profile Users can add their company name, phone, and address.
Company price list Users can add common prices so SiteGent can quote using their own rates.
WhatsApp message input User pastes a customer message or voice-note transcript.
AI job extraction SiteGent reads the message and identifies customer, job type, location, urgency, missing details, and likely quote lines.
Editable quote User can edit quote descriptions, quantities, and prices before saving.
Server-checked totals The server recalculates quote totals and VAT so totals cannot be faked from the browser.
Saved jobs User can save the customer, job card, quote, invoice, and message history.
Quote export User can export a saved quote as a clean print-ready document.
Invoice export User can export a saved invoice and mark it paid manually.
Payment request copy User can copy a simple WhatsApp payment request for the customer.
Feedback Pilot testers can send feedback from inside the app.

Why This Matters

  • Contractors do not want more admin software. They want faster quoting.
  • WhatsApp is already where many jobs start.
  • Faster quote response can help win more work.
  • Using the company price list makes the AI more practical and less generic.
  • Saved jobs help small teams stop losing customer details in chat threads.

What Makes SiteGent Different

SiteGent is designed around the contractor's real day: messages, prices, quotes, invoices, and follow-ups. It is not a general chatbot and not a complicated CRM.

  • It starts with a WhatsApp message.
  • It uses the contractor's own prices.
  • It keeps the quote editable.
  • It saves the job privately by company.
  • It reminds users to review prices before sending.

What Is Not Final Yet

SiteGent is live, but it is still an early product. The core workflow works, but the team is still improving:

  • First-time onboarding
  • Bulk or pasted price-list setup
  • More professional quote and invoice designs
  • Better quote confidence labels
  • More reliable scheduling from natural language
  • Monitoring, support process, and deeper production hardening
Important: SiteGent prepares draft quotes. Contractors must review quantities, prices, VAT, delivery costs, and dates before sending anything to customers.

Simple Demo Flow
